# Aniyomi Extensions

Personal Aniyomi-compatible anime extension repository.

## Add this repository to Aniyomi

Once extensions are published, use:

`https://raw.githubusercontent.com/MohammedEmad333/aniyomi-extensions/repo/index.min.json`

## Development

Extension modules live in `src/<lang>/<source>/`.

This project follows the Aniyomi extension API and repository format. It is not affiliated with Aniyomi or any content provider.
